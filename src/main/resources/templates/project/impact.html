Analysis level
Default comes from Settings. Inferred relationships use documented conservative rules.

How the score works

100 × (0.45·D/(N−1) + 0.40·T/(N−1) + 0.15·min(H,5)/5)
N
components in the selected level
D
distinct direct dependents
T
distinct transitive dependents (the component itself excluded)
H
longest shortest path to an affected component

LOW below 30, MEDIUM from 30, HIGH from 60 (configurable in Settings).
